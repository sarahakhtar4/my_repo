# Physical Design Scripting Learning Workspace

This workspace is designed to help you master Python and TCL scripting for physical design roles, with a focus on timing report analysis and other common tasks.

## 📁 Directory Structure

```
├── python_learning/          # Python tutorials and exercises
│   ├── basics/              # Python fundamentals
│   ├── timing_analysis/     # Timing report analysis scripts
│   ├── exercises/           # Practice problems
│   └── sample_data/         # Sample timing reports and test data
├── tcl_learning/            # TCL tutorials and exercises
│   ├── basics/              # TCL fundamentals
│   ├── eda_scripts/         # EDA tool scripting examples
│   └── exercises/           # Practice problems
├── projects/                # Combined Python+TCL projects
└── requirements.txt         # Python dependencies
```

## 🚀 Getting Started

1. **Set up Python environment:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Start with Python basics:**
   - Navigate to `python_learning/basics/`
   - Run through the numbered tutorial files

3. **Learn TCL fundamentals:**
   - Navigate to `tcl_learning/basics/`
   - Practice with the example scripts

4. **Practice timing analysis:**
   - Try the exercises in `python_learning/timing_analysis/`
   - Use sample data in `python_learning/sample_data/`
